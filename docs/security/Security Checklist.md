## Sign-off rule

Do not convert **BLOCKED**, **NOT RUN**, or **UNKNOWN** to **VERIFIED** without
attaching the named evidence. A dashboard screenshot or owner confirmation must
include the date and environment; a runtime check must record the command,
target, and result. The repository's production-mutation restrictions remain in
force (`AGENTS.md`, “The MCP config points at PRODUCTION”).
